# Screen Recorder (Ubuntu X11)

在 Ubuntu 的 X11 桌面会话里,框选一块锁定画幅比(16:9 或 3:2)的区域,录制其画面与系统声音,输出 1080p MP4(H.264 + AAC),画面不含鼠标光标。个人自用,追求稳定、够用、低打扰。

## 依赖
- Ubuntu,运行于 X11(Xorg)会话(不支持 Wayland)
- `ffmpeg`,需含 `libx264`、`aac` 编码器与 Pulse 输入(验证:`ffmpeg -encoders 2>/dev/null | grep -iE 'libx264|aac'`)
- PipeWire(经 `pipewire-pulse` 提供 Pulse 兼容层)或 PulseAudio,提供默认 monitor 源
- Python 3.10+

系统依赖(Ubuntu):
```bash
sudo apt install ffmpeg python3-venv
# 音频走 PipeWire 时(22.04+ 默认),确认兼容层已装:
sudo apt install pipewire-pulse
```

## 安装
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## 运行
```bash
.venv/bin/python -m app.main
```

## 使用
1. 选择画幅比(16:9 / 3:2)。
2. 点 **Select Region**,拖拽框选一个锁定该比例的矩形;松开鼠标后选区框会**保持显示**
   (标注尺寸与坐标),点一下选区(或按 **Enter/空格**)确认;重新拖拽可改选,**Esc / 右键**取消。
3. 确认之后,选区四周会留下一个**常驻边框**(青色边条 + 角部标记 + 尺寸标签),只要该区域
   还有效就一直显示在桌面上 —— **框在哪,就录在哪**,不必读状态栏文字。
   * 按住边条拖动 = 整体移动选框;按住**角上的手柄块**(四个角各自外扩的那一小块)拖动 =
     以对角为锚,按当前画幅比缩放(放大、缩小同一个手势)。
   * 边框只铺在区域外侧的边带上:区域内部照常可点,不会挡住正在被录的窗口;录出的画面
     里也不会出现边框的任何像素。
   * 某条边贴住屏幕边缘时,那一侧没有地方画边条(既无线也无手柄),该方向的缩放改用**对角**手柄。
4. 点 **Record** 开始,窗口实时显示已录时长(MM:SS,超 1 小时显示 HH:MM:SS);
   若这个窗口当时正压在选区上,它会在抓取开始的前一刻**从桌面上消失**,换成一条贴在
   选区之外屏幕边带上的**窄控制条**(只有已录时长和一个停止键;抓起来之前停止键暂不
   可点)。落点由算法定死、不可拖动,录制期间也不再变;**Stop** 后窗口回到原来的位置、
   原来的样子。窗口本来就不在选区上时一切照旧,不会出现控制条。
   若检测不到系统音源,会询问是否继续无声录制。
   录制期间边框变为**红色并带 REC 标记**,指示的就是正在被捕获的那块画面;此时边框
   **只读** —— ffmpeg 的抓取矩形在录制启动的一刻就固定了,想换位置或大小请先 **Stop**。
   录制中拖框会得到「停止录制后才能更改区域」的提示,画面与选框都不动。
5. 点 **Stop** 结束,文件保存到所选目录(默认 `~/Videos`)的 `screen_YYYYmmdd-HHMMSS.mp4`,窗口显示完整路径;
   停止后边框恢复青色,可以接着拖、接着缩放,再录一段。
6. 切换画幅比(16:9 ↔ 3:2)会让已选区域失效,常驻边框立即消失,需要重新框选;
   录制期间画幅下拉框禁用,不会出现「框还在、区域却被悄悄清空」的中间态。
7. 点 **Choose…** 可更改保存目录(默认 `~/Videos`);选择即时生效,仅当前会话有效。

## 边界(Scope)
- 只录系统声音,不录麦克风。
- 录制中不可更改区域(需先停止)。
- 常驻边框只是指示与操作层,不进画面、不抢焦点、不挡住区域内的窗口。
- 录制期间本应用自己的窗口(主窗口、录制控制条)也不进画面:压在选区上就收起,
  控制条只落在选区之外的屏幕边带上。**选区大到四条边带都放不下时是例外**(整屏选区是它的
  极端情形)—— 此时界面照样收起,控制条会被录进画面,还可能压住一段边条;控制条始终画在
  边条之上,所以停止键任何时候都点得到。窗口自己的像素仍然一个都不会进画面。
- 不含鼠标光标(`-draw_mouse 0`;屏幕上光标仍可见)。
- 无暂停/续录;一次「开始 → 停止」产出一个文件。
- 保存目录选择仅当前会话有效(重启后回到默认 `~/Videos`)。
- 单主显示器;不做多屏/跨屏。
- 仅 X11;Wayland 不受支持。

## 测试
```bash
.venv/bin/python -m pytest                      # 单元 + 逻辑测试(无需真实显示)
RUN_E2E=1 .venv/bin/python -m pytest tests/test_e2e_smoke.py   # 真机冒烟(需 X + ffmpeg + 音频)
```

`RUN_E2E=1` 的用例里含「选框不进画面」的抽帧检查:它在真实桌面上拉起主窗口与常驻边框
(`tests/e2e_frame_host.py` 子进程),录一段再抽帧逐像素比对,既确认边条确实画在区域之外,
也确认录出的 MP4 里没有一个像素来自边框。还有一条把主窗口**压在选区正中间**再录:它先证明
录制前那个位置确实是这个窗口(否则「画面里没有它」可能只是因为根本没画),再证明录制中那些
像素变回内容本身、控制条出现在选区之外,并且成片里既没有窗口也没有控制条的像素。屏幕放不下
该用例的区域时,前一类会自动 skip;最后这条不 skip —— 前提不成立就是失败。
